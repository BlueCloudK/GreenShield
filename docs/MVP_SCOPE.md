# MVP Scope

## Real

Authentication, workspace isolation, projects, targets, connection checks, scan execution, deterministic findings, evidence, risk score, report, and retest history.

## Mock/provider-backed

The included vulnerable/fixed target is a local provider used to produce reliable demo outcomes.

## Not implemented

Payments, invitations, role administration UI, SSO, external scan providers, LLM-as-judge, distributed queues, scheduled scans, email, compliance packs, and production-grade PDF generation.
