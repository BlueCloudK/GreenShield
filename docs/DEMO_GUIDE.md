# Sales Demo Guide

1. Register a new account and log in.
2. Create a project using the included demo target.
3. Connect the target and run Test Connection.
4. Select security tests and start the scan.
5. Open the report and select findings from the left list.
6. Show attack input, target response, evidence, impact, and remediation.
7. Switch the target to Fixed Mode and run a retest.
8. Confirm the finding changes to `Đã khắc phục` and history records the new result.

Use only the included target during a public presentation. Do not enter customer production credentials.
